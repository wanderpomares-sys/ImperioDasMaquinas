💡 DICAS IMPORTANTES
================================================================================

1. SEMPRE teste em dispositivo real
   DevTools enganam! O notch real é diferente do simulado.

2. LIMPE o cache antes de testar
   Ctrl+Shift+Delete (Chrome) — é importante!

3. DESINSTALE e REINSTALE o PWA
   Após fazer push, desinstale o app antigo e instale novamente.

4. USE git branch
   git checkout -b fix/mobile-icons
   Facilita rollback se necessário.

5. VALIDAR manifest.json
   python3 -m json.tool manifest.json
   Garante que não há erros JSON.

📞 EM CASO DE DÚVIDA
================================================================================

1. Logo não aparece?
   → Limpe cache (Ctrl+Shift+Delete)
   → Desinstale e reinstale PWA
   → Verifique manifest.json válido

2. Header ainda invade status bar?
   → Verifique viewport-fit=cover foi adicionado
   → Verifique CSS do .statusbar foi atualizado
   → Hard refresh (Ctrl+F5)
   → Teste em dispositivo real (não apenas DevTools)

3. Manifest.json com erro?
   → python3 -m json.tool manifest.json
   → Procure por vírgulas/aspas faltando
   → Verifique abre e fecha corretamente

4. Precisa de ajuda?
   → Veja troubleshooting em 01-GUIA-PASSO-A-PASSO.md
   → Leia CORRECOES_IMPLEMENTADAS.md (explicação técnica)
   → Consulte 02-manifest-COMENTADO.md (manifest)
