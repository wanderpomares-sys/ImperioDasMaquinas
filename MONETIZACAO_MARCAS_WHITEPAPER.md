## 📋 SUMÁRIO EXECUTIVO

**Jogo:** Império das Máquinas (PWA mobile)  
**Público:** Entusiastas de construção/máquinas pesadas  
**Modelo:** Free-to-play com integração orgânica de marcas  
**Oportunidade:** Não é publicidade intrusiva — é **conteúdo do gameplay**

---

## 🎮 O JOGO EM 2 MINUTOS

Jogador gerencia uma frota de máquinas pesadas (escavadeira, rolo compactador, etc) completando contratos de construção ao longo de 20 anos.

**Mecânica central:** Cada máquina precisa de manutenção. Manutenção é onde marcas entram.

---

## 🔄 COMO MARCAS INTEGRAM AO GAMEPLAY

### Cenário: Manutenção de Máquina

```
ANTES (genérico):
jogador clica "Fazer Manutenção"
├─ Escolhe: Oficina Rápida (5 dias, R$5k, qualidade 80%)
└─ Máquina volta ao trabalho

DEPOIS (COM MARCA REAL):
jogador clica "Fazer Manutenção"
├─ Escolhe: Oficina Rápida
├─ Escolhe: Oficina Parceira Real 🎯
│         (2 dias, R$8k, qualidade 100% + 10% bônus)
│         ├─ Logo da marca aparece
│         ├─ Vídeo de 5s da marca exibe
│         ├─ Botão "Catálogo da Marca"
│         └─ Misqueta é registrada no analytics
└─ Máquina volta ao trabalho
   (com status "Manutenção RoadForce" visível)
```

**Diferença:** A marca não é anúncio — é um **benefício real** que o jogador escolhe.

## 💡 Por que jogadores escolhem marca?

### Análise de Trade-off

```
GENÉRICA (R$5.000)
├─ Custo: Barato
├─ Tempo: 5 dias (máquina parada)
├─ Qualidade: 80% (retorna com eficiência reduzida)
├─ Marca: Nenhuma
└─ Impacto econômico: Ruim pra negócio

PARCEIRA REAL (R$8.000) 🎯
├─ Custo: +60% (R$3k a mais)
├─ Tempo: 2 dias (-3 dias = maior produção)
├─ Qualidade: 100% + 10% bônus (máquina roda melhor)
├─ Marca: SIM (reputação + missão)
└─ Impacto econômico: Retorna em 2 contratos (ROI garantido)

PRÓPRIA (R$3.000)
├─ Custo: Inicial R$500k, depois barato
├─ Tempo: 1 dia (melhor)
├─ Qualidade: 100% (normal)
├─ Marca: Nenhuma
└─ Impacto: Longo prazo
```

**Insight:** Jogador racional escolhe marca quando o bônus compensa. **Isso é orgânico.**

## 📊 DADOS COLETADOS POR MARCA

Quando jogador escolhe sua marca (RoadForce, PowerFuel, etc), coletamos:

### Métricas de Engajamento

```
Impressão Qualificada:
├─ Jogador viram logo + vídeo
├─ Dados demo: País, idioma, dispositivo
└─ Qualidade: Real player, não bot, jogando genuinamente

Tempo de Sessão:
├─ Quanto tempo ficou vendo marca (5s vídeo = mínimo)
├─ Quantas vezes clicou "Catálogo"
└─ Dwell time total em tela da marca

Ação Convertida:
├─ Jogador ESCOLHEU sua marca (não foi forçado)
├─ Completou contrato com sua marca (durabilidade prova)
└─ Voltou a escolher marca (fidelidade)

Impacto Econômico:
├─ Bônus R$ gerado no jogo ($5k extra se usou marca)
├─ Ciclo de repetição: cada 30-60 dias precisa manutenção
└─ Lifetime Value: marca aparece X vezes em carreira de 20 anos
```

## 💎 POSICIONAMENTO: 5 CATEGORIAS

Cada categoria de marca tem **papel diferente** no jogo:

### 1️⃣ PNEUS (RoadForce → Pirelli / Michelin / Goodyear)

```
Integração: Manutenção de pneus
Bônus Gameplay: Desgaste pneu -30% por 60 dias
Frequência: ~8x/ano (média)
Engajamento: "Especialista em Pneus Pesados"

Pitch pra marca real:
├─ Atinge técnicos/gestores que especificam pneus
├─ Dura 60 dias (percepção durabilidade)
├─ Fidelidade: "10 manutenções = Pneu Premium grátis"
└─ Dados: Quantos jogadores escolhem seu pneu em ano 1, 5, 10...
```

### 2️⃣ ÓLEOS (SynthFlow → Mobil / Shell / Castrol)

```
Integração: Revisão de óleo
Bônus Gameplay: Intervalo manutenção -20% (permanente)
Frequência: ~4x/ano (média)
Engajamento: "Especialista em Lubrificantes"

Pitch pra marca real:
├─ Atinge mecânicos e gerentes de frota
├─ Percepção: "Óleo que reduz custo de manutenção"
├─ Permanente: Uma compra = benefício pro resto da carreira
└─ Dados: Adoção por tipo de jogador (conservador vs agressivo)
```

### 3️⃣ PEÇAS (MegaParts → Caterpillar / Komatsu / JCB)

```
Integração: Substituição de peças
Bônus Gameplay: Confiabilidade +95% (permanente)
Frequência: ~6x/ano (média)
Engajamento: "Confiança em Peças Originais"

Pitch pra marca real:
├─ Atinge tomadores de decisão de manutenção
├─ Percepção: "Peça que não falha"
├─ Dado crítico: % de jogadores que escolhem peça real em alta carga
└─ Dados: Retenção (continuam comprando após primeira compra?)
```

### 4️⃣ COMBUSTÍVEL (PowerFuel → Petrobras / Shell / Esso)

```
Integração: Abastecimento
Bônus Gameplay: Consumo -15% (permanente)
Frequência: ~50x/carreira (alta!)
Engajamento: "Parceiro de Combustível Confiável"

Pitch pra marca real:
├─ Volume alto de touchpoints
├─ Percepção: "Economiza combustível = economiza custo total"
├─ Dados: Frequência de abastecimento = fidelidade indicador
└─ Dados: A quanto tempo levaria pra depreciar em favor de concorrente?
```

### 5️⃣ SERVIÇOS TÉCNICOS (TechRep → Rede Autorizada)

```
Integração: Diagnóstico e reparos complexos
Bônus Gameplay: Diagnóstico grátis vitalício
Frequência: ~5x/carreira (baixa mas impactante)
Engajamento: "Parceiro Técnico Certificado"

Pitch pra marca real:
├─ Atinge gestores de manutenção estratégica
├─ Percepção: "Serviço que você confia em momentos críticos"
├─ Dados: Quando jogador escolhe técnico? (eventos, proativamente?)
└─ Dados: Problema-solving (completou contrato crítico com ajuda?)
```

## 💰 MODELOS DE PREÇO

### Opção 1: CPM (Custo Por Mil Impressões)

```
Standard Rate: R$ 15-20 CPM

Exemplo:
├─ 100.000 jogadores veem marca em mês
├─ Taxa: R$ 18 CPM
├─ Faturamento: 100k / 1000 × R$ 18 = R$ 1.800/mês
└─ 12 meses = R$ 21.600/ano
```

**Vantagem:** Simples, previsível  
**Desvantagem:** Não reflete engajamento real

---

### Opção 2: CPA (Custo Por Ação)

```
Action = "Jogador escolhe marca e completa contrato"

Standard Rate: R$ 50-100 por ação

Exemplo:
├─ 1.000 ações/mês
├─ Taxa: R$ 75 CPA
├─ Faturamento: 1.000 × R$ 75 = R$ 75.000/mês
└─ 12 meses = R$ 900.000/ano
```

**Vantagem:** Paga por resultado real  
**Desvantagem:** Volatilidade mensal

---

### Opção 3: HÍBRIDA (Recomendado)

```
Base: R$ 15 CPM (garantido)
Bônus: R$ 25 por ação de fidelidade (2ª+ escolha)

Exemplo:
├─ 100.000 impressões/mês: 100 × R$ 15 = R$ 1.500
├─ 500 ações de fidelidade: 500 × R$ 25 = R$ 12.500
└─ Total mensal: R$ 14.000 = R$ 168.000/ano

Benefício: Win-win
├─ Marca garante mínimo (CPM base)
├─ Marca escala com sucesso (CPA bônus)
└─ Alinhado: mais engajamento = mais ganho
```

## 📋 PROCESSO DE ONBOARDING PARA MARCA REAL

### Fase 1: Acordo (2-4 semanas)

```
1. Marca assinale NDA
2. Defina categoria (pneus, óleo, peças, combustível, serviço)
3. Confirme bônus do jogo (ex: -30% desgaste)
4. Defina modelo de preço (CPM, CPA, Híbrido)
5. Logotipo, website, contato oficial
6. Formas de pagamento e reporte
```

### Fase 2: Implementação (1-2 semanas)

```
1. Substitua marca fictícia por real no código
2. Atualize assets (logo, cores, website)
3. Ative em ambiente de staging (teste)
4. Valide: logo aparece correto, vídeo exibe, links funcionam
5. Deploy em produção (release na App Store + Google Play)
```

### Fase 3: Lançamento (2-4 semanas)

```
1. Anúncio no Twitter/LinkedIn: "Agora com parceria [Marca]"
2. Newsletter: 100k jogadores recebem anúncio
3. In-game notification: "Novo parceiro desbloqueado: [Marca]"
4. Press release (opcional)
5. Monitorar: Are jogadores interessados? Qual taxa de adoção?
```

### Fase 4: Otimização (Contínua)

```
Mês 1-3: Dados iniciais
├─ Impressões reais
├─ Taxa de engajamento
├─ Primeira adopção
└─ Ajustar bônus se necessário (muito baixo = não escolhem)

Mês 4+: Dados de fidelidade
├─ Quantos repeats?
├─ Lifetime value por jogador
├─ Segmentação: quem mais usa? (por país, estilo de jogo, etc)
└─ Oportunidades de upsell
```

## 🚨 RISCOS E MITIGAÇÃO

### Risco 1: Jogador recusa marca (muito caro)

```
Problema: Bônus de R$8k é caro demais
Mitigação: Ofereça tier de bônus (pequeno/médio/grande)
          ou desconto progressivo na 2ª escolha
```

### Risco 2: Marca demora pra aparecer (jogador esquece)

```
Problema: Não faz manutenção = não vê marca
Mitigação: Missões de fidelidade ("use marca X 10 vezes")
          In-game notification ("Nova parceria desbloqueada")
```

### Risco 3: Botão "Catálogo" não converte (link errado)

```
Problema: Jogador clica mas bounce rate alto
Mitigação: Landing page custom por marca (não página inicial)
          Algo relevante: "Pneus para máquinas pesadas" (não homepage)
```

### Risco 4: Dados insuficientes (não sabe ROI)

```
Problema: Marca gasta X, ganha vendas Y, não conecta
Mitigação: Relatório mensal detalhado com UTM tracking
          Código de desconto custom pra medir conversão real
          Survey pós-compra: "Ouviu falar no jogo Império?"
```

## APÊNDICE: Perguntas Frequentes

**P: Como garantem que não é ad-bloqueado?**  
R: Não é anúncio — é conteúdo do jogo. O jogador escolhe ver. Impossível bloquear.

**P: Qual o tráfego esperado mês 1?**  
R: 50-100k impressões (conservador). Cresce mês 2-6 enquanto jogadores descobrem.

**P: Posso customizar o bônus?**  
R: Sim. Trabalhamos juntos. Pneus? -30% desgaste. Óleo? -20% intervalo. O que faz sentido pra marca.

**P: E se marca real tiver problema de qualidade?**  
R: Desenvolvemos relatório "detractors" — jogadores que escolhem e não repetem. Isso vira feedback valioso.

**P: Funciona fora do Brasil?**  
R: Sim. Jogadores em 50+ países. Segmentaremos por região se quiser (ex: R$ X em BR, Y em US).
